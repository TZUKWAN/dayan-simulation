# 大衍 DAYAN 平台手册 v2.0

> 社会仿真基础设施 · 五范式一站式 · 2026-11-08

## 1. 平台概览

大衍 DAYAN（本仓库）是独立的社会仿真基础设施，覆盖五大仿真范式：

| 范式 | 引擎 | 代表模型 |
|---|---|---|
| ABM | 主体建模 | Schelling、Sugarscape、意见动力学 14 种、Mark-0 宏观 |
| SD | 存量流量 ODE（RK4） | Goodwin、Solow、World3-lite、SIR 族 |
| 博弈 | 收益矩阵 + 纳什/演化 | PD/鹰鸽/猎鹿/公共品 + 12 种学习规则 |
| 运筹 | scipy linprog/milp | 运输/LP（propose-dispose 协议） |
| CA | 元胞自动机 | Wolfram Rule 30/90/110/184、Life、BML、NS 交通 |

**目录规模**：556 条登记（482 具名模型 + 22 应用场景 + 52 软件参考），
其中 **339 条基准通过 + 12 条原型可跑（应用场景配方）**；290 个模型经统一
工厂（`dayan/model_index.py`）可从 HTTP API 一键运行。

**质量合同**：全平台测试 `tests/run_all.py`（25 套件，200+ 断言）；
货币/物质守恒残差 ~1e-13；遮蔽审计零命中；三主权边界（引擎管状态、
LLM 管意义、研究者管理论）。

## 2. 快速开始

```bash
cd dayan-simulation

# 全平台测试
python tests/run_all.py

# 统一入口跑任意模型（YAML 场景规约）
python experiments/run_spec.py --spec tests/fixtures/scenario_smoke.yaml

# 启动平台服务器（操作台 + 演示页 + AI 助手）
python -m dayan.server     # http://127.0.0.1:8899
```

- `/`：仿真操作台（目录搜索/状态筛选/一键运行/结果绘图）
- `/demo`：campaign 真实数据可视化演示页
- `/api/catalog`：556 条目录（含状态字段）
- `/api/models/runnable`：290 个可运行模型清单
- `/api/run`：`POST {model_id, ticks, parameters}` 统一运行
- `/api/ai/chat`：AI 助手（需本地 LM Studio :1234 挂 Qwen3.5-4B）

## 4. 统一执行接口（规范 2.2）

所有模型实现 `DayanModel` 合同（`dayan/core.py`）：

```python
class MyModel(DayanModel):
    model_id = "XXX000"
    clock_type = "fixed_step"   # 或 ode/sde/jump/des

    def initialize(self, context, parameters, population, topology, rng): ...
    def validate_state(self) -> list[str]: ...
    def observe(self) -> dict: ...
    # 按 clock_type 实现其一：
    def step(self, t, dt): ...                    # fixed_step
    def derivatives(self, t, x) -> np.ndarray     # ode（配 self.x）
    def drift/diffusion(self, t, x)               # sde
    def event_intensities / apply_jump            # jump（Gillespie）
```

`dayan.model_index.run_model(mid, ticks, parameters)` 统一驱动；
新模型在 `model_index.py` 注册即可被 `/api/run` 运行。

## 5. 旗舰耦合器（dayan/coupled.py）

`CoupledSimulation`：Goodwin SD 核（利润挤压有界循环）× 微观就业 ABM。

```python
from dayan.coupled import CoupledSimulation
r = CoupledSimulation(mode="cyclic", seed=7).run()
# mode: one-way（SD→ABM 工资注入）/ cyclic（ABM 就业率弱反馈 SD）/
#       reference（同种子无耦合对照，逐位复现）
```

## 8. AI Agent 层（dayan/agent/）——方法论汇聚与灵活改模型

设计目标：**汇聚所有方法论 → 用户自然语言需求 → 内置 AI Agent 灵活组合/改参/对照**。
LLM 与数据后置，Agent 骨架即刻可用。

四层结构：
- **metadata.py** 能力元数据：290 个可运行模型逐一探针 →
  data/model_capabilities.json（参数清单含默认值 + 数值观测量 + 协议）
  —— Agent 的"眼睛"，未来 LLM 直接读这份说明书做语义决策
- **composer.py** 确定性组合引擎（Agent 的"手"）：sweep（参数扫描）/
  ensemble（多种子稳健性）/ compare（跨模型对照）/ compose（流水线 +
  前级终值字段注入后级参数 handoff）
- **tools.py** 工具合同：7 个 function-calling 工具（search_models /
  get_capabilities / run / sweep / ensemble / compare / compose），
  tool_manifest() 即未来 LLM 的函数调用清单；执行永远走确定性实现（三主权）
- **intent.py + agent.py**：中文关键词规则路由（运行/扫参/集成/对比/组合/搜索）
  当前无 LLM 即可用；set_llm_planner(fn) 可插拔——未来 LM Studio 上线
  注入 planner 即自动切换，规则路由永远保底

接入：POST /api/agent {text} → {plan, summary, executed}；
UI AI 面板已接（Agent 优先，LLM 聊天回退）。

示例：
- "运行 NET106" → run
- "对 NET106 扫参 density 0.1 0.3 0.5" → sweep
- "比较 NET110 和 NET111" → compare
- "组合 ECO015 ECO017" → compose（Solow k → AK 初始资本 handoff）
