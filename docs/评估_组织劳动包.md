# 组织/劳动社会学包 评估报告（R5 候选 · 设计文档 §3.5）

> 状态：**评估完成，骨架暂缓**。依据：实现成本/边际价值权衡 + 既有覆盖度审计。

## 1. 设计文档要求（§3.5）
- 世界观：科层/车间/平台上的劳动过程（Braverman 去技能化、Edwards 控制体制）
- 制度变量：监控强度、计件/计时、科层层级数、民主管理度
- 因变量：异化量表（复用政治经济学包器具）、去技能化率、控制-反抗动力学
- 校准靶：异化量表的组间方向预期（v0/v1 已证）

## 2. 既有覆盖度审计（关键发现）
| 需求 | 已覆盖位置 | 差距 |
|---|---|---|
| 异化量表（Seeman 五维） | polecon 包 alienation.py（600+ 叙事实测） | **零差距，直接复用** |
| 监控/控制 → 异化 | polecon 包雇佣结构（受雇 vs 自营 无力感 3.05 vs 2.29） | 控制体制维度未展开 |
| 去技能化 | 未覆盖 | polecon 有技能字段，可加技能退化动态 |
| 民主管理度 | polecon 合作社制度（社员无力感 1.86-2.19 全场最低） | **已实质覆盖** |
| 劳动过程话语 | transaction.py 拜物教通道 | 复用即可 |

**结论：组织/劳动包 80% 的核心变量已在政治经济学包内实质覆盖**——它是"政治经济学包的劳动过程深化子模块"，而非独立学科包。

## 3. 边际价值评估
- **高价值新增**：去技能化动态（技能退化）、监控强度的连续调节（当前是雇佣二元）
- **低价值新增**：科层层级（玩具经济无科层）、计时/计件（当前已是计件）
- **成本**：七件套骨架 + 验收 ≈ 社会学包的 60% 工作量

## 4. 建议（三选一）
| 方案 | 内容 | 适用 |
|---|---|---|
| A. 并入 polecon | 在 polecon 加 `labor_process` 制度变量（监控强度/去技能化开关） | **推荐**：避免包碎片化，变量联动最自然 |
| B. 独立组织/劳动包 | 完整七件套，聚焦控制体制谱系（简单控制→技术控制→科层控制，Edwards 三阶段） | 若要做 Edwards 控制体制谱系的系统实验 |
| C. 暂缓 | 优先 R5（人工复核/跨模型/CGSS）与 OASIS 大规模实验 | 若资源紧张 |

## 5. 推荐执行（方案 A 的具体增量）
1. polecon `Params` 加：`monitor_intensity ∈ [0,1]`（监控→受雇者无力感加成，经叙事 prompt 传递处境描述）
2. polecon `Agent` 加：`skill` 动态退化（去技能化：`skill *= (1 - deskill_rate × 受雇tick)`）
3. 验收：监控强度↑ → 受雇者异化量表↑；去技能化率↑ → 产出↓、失业↑
4. 工作量：~0.5 天，复用全部既有测试框架
