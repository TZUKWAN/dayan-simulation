# 模型源码审查与能力台账

本轮按运行工厂逐项审查。数学机制、运行探针、源数据绑定、校准和独立测试各自留证。正文记录 20 个不同工厂的审查，`NET-SIR` 另列为 `NET053` 的兼容入口。用真实引擎计算的定向测试包括种子 7 的重复运行、种子 23 的独立运行、单项参数或干预对照和规定数值不变量。相关哈希进入 [核心运行凭证](verification/vnext/core_model_runs.json)。探针仅测有限输出、构造及运行。 [完整目录台账](verification/vnext/model_ledger.csv)

## 宏观、产业与行为模型

| 模型及源码 | 理论、状态和算法 | 参数、边界和本轮实际核验 |
| --- | --- | --- |
| ECO001 [LeontiefQuantityModel](../dayan/models/eco_models.py) | 开放投入产出数量模型。给定技术系数矩阵 (A)、最终需求向量 (d)，从 (x=d) 逐次计算 (x\leftarrow d+Ax)。 [Leontief 1936](https://doi.org/10.2307/1927824) | (A) 为部门技术系数，(d,x) 使用一致的部门生产单位。实际使用显式 (A)，要求非负且谱半径小于 1。二部门结果与独立线性代数解一致，需求翻倍时产出翻倍。默认矩阵只用于机制演示。 |
| ECO015 [SolowModel](../dayan/models/wave2.py) | 一状态、人均资本 (k)，(A=1,n=0)，(\dot k=sk^\alpha-\delta k)，RK4 更新。 [Solow 1956](https://doi.org/10.2307/1884513) | (s,\alpha) 为比例，折旧率每模型时间单位。稳态公式适用于正折旧和 (\alpha<1)。核对初值、解析稳态和提高储蓄率的过渡轨迹。模型无人口和技术增长。 |
| ECO017 [AKModel](../dayan/models/eco_models.py) | (Y=Ak)，(g=sA-\delta)。固定步 Euler 推进 (k)，另给按实际时间计算的解析指数基准。 [Rebelo 1991](https://doi.org/10.1086/261764) | (s) 为储蓄率，(A,\delta,g) 按模型时间计率，(k) 归一化资本。拒绝使单步资本非正的步长。初值 2 下逐步比对两种公式，增加 (A) 后增长响应符合模型。 |
| ECO019 [GoodwinCatalogModel](../dayan/models/eco_final.py) | 工资份额和就业率联立方程。例示核心采用 `nu,delta,a,b` 表示资本产出系数、折旧、工资调整截距和响应。数值积分由相同 Goodwin 核心执行。 [Goodwin 1967](https://www.icts.res.in/sites/default/files/Goodwin_growth_cycle_1967.pdf) | 两状态均为比例。指定正初态验证轨迹、变化率敏感性与源方程，保留经济域外风险。历史独立 Goodwin 积分与耦合合同作为补充证据。 |
| BEH001 [SchellingModel](../dayan/models/beh_abm.py) | 两组居民和空位，周期 Moore 邻域，按邻居相似比与阈值判断搬迁。随机空位分配后观测隔离、不满率和持久身份。 [Schelling 1971](https://doi.org/10.1080/0022250X.1971.9989794) | 网格单位格，密度和阈值为比例，按离散更新计时。验证阈值为零时不满率、居民不增不减。周期边界和批量移动为实现简化。 |
| BEH005 [EpsteinViolenceModel](../dayan/models/beh_abm.py) | 抽象格点社会机制。怨愤为困难度乘合法性剩余，风险由局部状态计算，随后经过离散行动及状态更新。 [Epstein 2002](https://doi.org/10.1073/pnas.092080199) | 参数含主体数、网格、阈值、视野与刑期。合法性为 1 时怨愤为零，复核同种子轨迹及既有独立状态测试。结果限于人工网格及研究定义。 |
| BEH016 [FriedkinJohnsen](../dayan/models/opinion.py) | 用初值的锚定权重 (g) 与当期其他个体平均值线性组合，同步更新无量纲意见。 [Friedkin 与 Johnsen 1990](https://doi.org/10.1080/0022250X.1990.9990069) | (n) 为人数，(g\in[0,1])，每步一次同步，适用至少两名主体。(g=1) 时所有意见不变，普通锚定减少样本离散度。完全混合、同一 (g) 为简化。 |
| BEH018 [DeffuantWeisbuch](../dayan/models/opinion.py) | 独立随机采样一对主体，距离不超过 (d) 时按 (μ) 对称调整。意见值和距离为无量纲，均值、离散度、簇数来自当前状态。 [Deffuant 等 2000](https://doi.org/10.1142/S0219525900000078) | (d) 为信任边界，(μ) 为妥协比例，步为一次抽样。验证均值守恒、宽阈值下离散度下降、(μ=0) 意见不变。主体中的随机对允许相同索引并跳过该轮。 |

| --- | --- | --- |
| NET052 [SISModel](../dayan/models/wave2.py) | 闭合混合 SIS，(\dot I=\beta I(N-I)/N-\gamma I)，RK4，(I_\star) 为地方病比例。 [Kermack 与 McKendrick 1932](https://doi.org/10.1098/rspa.1932.0171) | (I) 人数，(i_0) 初始比例，(β,γ) 每模型时间计率。零传播的指数衰减与数值结果一致。区间及步长需按闭合模型条件选择。 |
| NET053 [SIRModel](../dayan/models/benchmarks.py) | (S\to I\to R)，感染 (β SI/N)，移出 (γ I)，固定人口和永久移出，RK4。 [Kermack 与 McKendrick 1927](https://doi.org/10.1098/rspa.1927.0118) | 观测为仓室人数，初始感染人数和转移率来自实际参数。验证人口守恒、零传播下 (S) 不变。NET-SIR 使用同一工厂。 |
| NET055 [SEIRModel](../dayan/models/benchmarks.py) | 增加潜伏仓 (E\to I) 的指数转移率 (σ)，与其余 SIR 率同一时钟。 [Hethcote 2000](https://doi.org/10.1137/S0036144500371907) | (S,E,I,R,N) 为人数，转移率为时间倒数。验证人口守恒和零传播下易感仓不变。潜伏时长采用指数状态离开率，未考虑个体时长分布的其他族。 |
| NET061 [AgeContactSEIRModel](../dayan/models/net_final16.py) | 三组 SEIR，组暴露率 (β\sum_j C_{ij} I_j/N_j)，固定步内用上一个状态计算三个转移。组状态和边的接触率来自实际矩阵。 [Anderson 与 May 1985](https://doi.org/10.1017/S002217240006160X) | (C) 为每人每模型时间接触率。移除重复人口归一化，验证首步手算、总人数守恒、九条组级关系和零传播。接触矩阵是可编辑情景输入。 |
| NET106 [NSModel](../dayan/models/traffic.py) | 周期单车道的加速、前距限速、随机慢化、同步移动。每辆车有固定 ID、格点和速度。 [Nagel 与 Schreckenberg 1992](https://doi.org/10.1051/jp1:1992277) | 速度格/更新，密度与慢化概率为比率。逐帧检查 ID、车格唯一性和流量对慢化的变化。物理秒、长度和道路拓扑由具体研究定义另校准。 |
| NET113 [SocialForceModel](../dayan/models/pedestrian.py) | 接近目标的驱动项、局部行人排斥和墙限制，离散积分并检测出口。 [Helbing 与 Molnár 1995](https://doi.org/10.1103/PhysRevE.51.4282) | (n) 为主体数，坐标为场景长度，期望速度为场景长度/时间。核对数目守恒、持续主体状态与速度参数改变的轨迹。限于基础房间和出口规则。 |
| CPL001 [RoadEvacuationModel](../dayan/models/evacuation_coupled.py) | 道路／人口端口和本地平面投影，前态可见队列约束装载，步行和车运动均按分钟积分。位置、队列、风险和公交事件在一次执行内取样。 [案例及来源](VNEXT_RESEARCH_CASES.md) | 人数、米、分钟、人/车次分别保留。复核数据版本、干预时点、载荷守恒、主体位置同步和实际走势。同导出案例为抽样情景机制，区域行为参数和两处设施为显式假设。 |

## 排队与动态系统

| 模型及源码 | 理论、状态和算法 | 参数、边界和本轮实际核验 |
| --- | --- | --- |
| SYS002 [MMCQueueModel](../dayan/models/sys_models.py) | Poisson 到达，指数服务，有限台数 FIFO，离散步读数及 Erlang-C 解析参考。 [Kendall 1953](https://doi.org/10.1214/aoms/1177728975) | (λ,μ) 为每模型时间到达和服务率，等待为时间单位。稳态参考限 (λ<cμ)。验证服务开始及结束计数的顺序与提高服务台数的参考等待下降。 |
| SYS003 [ErlangBModel](../dayan/models/sys_models.py) | (M/M/c/c)，忙满立即阻塞，理论 (B_c=aB_{c-1}/(c+aB_{c-1}))。观察累计阻塞与总到达。 [排队模型原始定义](https://doi.org/10.1214/aoms/1177728975) | (a=λ/μ) 为无量纲业务量，(B) 为概率。测试 (c=2,a=3) 的解析值与负荷边界。实际模拟按步聚合到达与释放，短窗仿真阻塞率有离散和抽样误差。 |
| SYS006 [MMInfQueueModel](../dayan/models/sys_models.py) | 同次 Poisson 到达全部获得服务，指数服务寿命，观测时间加权在系统人数与 (λ/μ)。 [Little 1961](https://doi.org/10.1287/opre.9.3.383) | 时间倒数为率，在系统人数为人数。倍改服务率时解析占用随之改变。有限步边界结算和启动时未稳态的样本误差保留。 |
| SYS007 [MD1QueueModel](../dayan/models/sys_models.py) | 连续 Poisson 到达时间，确定性服务时长 (1/μ)。以 (s_i=\max(a_i,d_{i-1})) 排 FIFO，累计已开始服务的真实等待。 [Kendall 1951](https://academic.oup.com/jrsssb/article/13/2/151/7026631) | 仅允许 (λ<μ)，未开始服务的等候者独立计数。有实际被服务观测才计算样本平均。核对计数守恒和 Pollaczek–Khintchine 稳态公式。 |
| SYS024 [DynamicStructureDEVModel](../dayan/models/sys_extras.py) | 有界工作池，周期检查待办数量并调整工人数，服务受可用工人的限制。到达、等待、服务与完成在同一循环推进。 [Barros 1997](https://doi.org/10.1145/268403.268423) | 到达和服务率每模型时间计，工作人仅在 1–4 范围。验证各分量任务守恒和零到达基线。是动态工作池原型，完整事件网络形式系统超出本实现。 |

除代表性研究的逐场景数据输入与校准结果外，以上机制审查记录不授予真实地区预测能力。参考指纹对应整个执行源码。源码变化时，目录自动撤回旧的当前审查标识，历史依据仍可查询。
