# 实验设计书：toy_capitalism_v0（MVP）

> 项目：msim——马克思主义理论的大模型社会仿真实验台（独立项目）。
> 版本：v0（2026-11-06）。状态：已实现并完成首轮四组运行。
> 设计原则全文见 `../llm_sim_survey/00_总览与项目设计.md`（外部文献基础在同目录 01–03 报告）。

## 1. 研究对象与定位

**模式 B（涌现探索）为主 + 模式 A（机制验证）起步**：观察 LLM 玩具经济中是否
自发涌现马克思主义政治经济学预言的结构性现象，并以规则基线差分归因"LLM 语义层"的增量。

**方法论自我限定**：本实验的一切结论均为"充分性证明"（某机制设定下能长出某现象），
不构成对历史唯物主义"规律"必然性的证明；异化/拜物教的测量是**指示器**而非"检验"。

## 2. 世界设定（层1 制度结构，引擎强制，对 LLM 遮蔽）

- 200 个居民 agent；单一消费品 + 一种设备（资本品，固定价 P_K=8，从设备部门购买，
  购买支出作为设备部门收入当期等量回流——两大部类结构，货币严格守恒）。
- 生存方式：受雇（被经营者雇佣，计件工资率×技能）或自营（自身技能×A 产出，按参考价出售）。
- 制度门槛：持有设备且积蓄足付工资缓冲者方可雇人经营（设备不可自给，须积累购买）；
  设备带来生产率加成（κ=0.6，"机器协作"）。
- 撮合：价格偏好×随机扰动（±15%）排序，便宜者占优但不独占；订单制生产（无库存）。
- 消费：维生线 1.5 单位 + 超出部分 MPC 0.75，封顶 6 倍维生线。
- 无政府、无信贷、无租金（v0 制度真空基线；这些是后续制度实验的自变量）。

## 3. 层2 LLM 语义层

- 模型：**Qwen3.5-4B @ LM Studio（本地）**——唯一模型（用户指定的机器性能约束；
  跨模型稳健性检验因此**挂起**，用种子稳健性部分替代，见 §6）。
- 决策空间（自然语言 JSON）：求职/自营/开业/购设备/观望；经营者：计件工资率、售价、
  用工上限 hire_cap、扩产意向。
- 决策周期：每 4 tick 一次（25% agent 为 LLM agent，其余为规则填充——混合人口设计）。
- 遮蔽设计（已审计通过）：prompt 无任何理论词汇（资本/剥削/剩余/阶级/异化等零命中）；
  制度结构由引擎强制；理论词汇只在测量端出现。
- 规则回退：解析失败回退规则策略并计数（实测回退率 0）。
- 推理加速：assistant 预填充空 think 块关闭思考模式（0.2s/次 vs 6-11s/次）。

## 4. 层3 测量管道

| 管道 | 测量 | 校准靶 |
|---|---|---|
| 分布 | 基尼、top10/top1 份额、双形态拟合（下层指数+上尾 Pareto, KS） | Yakovenko 双形态 |
| 剩余占有 | 逐 tick 剥削率代理（有雇员企业经济利润/工资单）、劳动份额 | 劳动份额 0.5–0.7；s′代理量级 1–2（口径声明见 data/calibration_targets.md） |
| 阶级结构 | 四位置（失业/受雇/自营/经营者）占比与转移矩阵 | 类结构存在性 |
| 异化 | Seeman 五维量表（叙事→LLM-judge→1–5 分），组间对比 | 方向性预期：无力感 worker>self；失业者最高 |

## 5. 假设与判据（预注册文本 v0）

- **H1（涌现·阶级）**：无任何初始阶级设定的玩具经济中，自发涌现稳定的四位置结构，
  且受雇关系持续存在（判据：末 30 期 worker+employer 期望 > 0，位置转移矩阵主对角占优）。
- **H2（涌现·不平等）**：财富分布显著不平等（基尼 > 0.2）且呈下指数+上尾偏厚双形态（定性）。
- **H3（机制·剩余占有）**：有雇佣关系企业的经济利润（收入−工资−折旧价值）系统为正，
  即利润可审计地来自雇佣劳动的产出超出工资支出（**代理口径**，非 s/(v) 本身）。
- **H4（探索·异化排序）**：Seeman 五维组间排序符合理论方向——
  无力感：worker > self；总分：unemployed > worker > self（方向性判据，不做显著性强主张）。
- **H5（LLM 增量）**：LLM 组与规则基线在经济结构指标上有系统差异
  （p_ref 轨迹、集中度、企业数），即语义层不只是噪声实现。
- **H6（消融稳健）**：去除人设背景（nopersona）后，H4 的组间排序方向不变。

**失败条件**：经济死锁（无雇佣关系）；LLM 决策回退率 > 30%；测量管道 NaN；
叙事评定回退率 > 30%。

## 6. 效度设计（层4）

- **基线 A（规则 agent）**：同参数、同种子、零 LLM——差分归因语义层（`--mode rule`）。
- **消融 B（人设消融）**：去除 persona 背景重跑（`--no-persona`）——
  防 persona 构造伪影（arXiv 2610.16498 的警告）。
- **稳健性 C1（种子）**：换种子重跑（s43）；**C2（跨模型）挂起**——
  用户约束仅允许 Qwen3.5-4B，跨模型检验记录为待补项。
- **校准 D**：定性靶对照（见 data/calibration_targets.md）；定量靶（CGSS/IO 表）阶段 2 接入。
- **可复现**：固定 seed + 锁定模型 + 响应缓存（cache.jsonl）+ 全量调用日志（llm_log.jsonl）
  + config.json 快照 + 金钱守恒逐 tick 检验。

## 7. 首轮运行结果摘要（2026-11-06，四组）

见 `../reports/comparison_mvp_v0.md`（组间对比）与各 run 目录内 REPORT.md。
要点：H1–H5 首轮全部方向性成立；H4 排序与理论预期一致
（无力感 worker 3.05 > self 2.29；总分 unemployed 15.75 > worker 10.36 > self 8.89）；
LLM 组涌现规则组没有的价格战（p_ref −60%）与财富集中（基尼 +137%）。

## 8. 已知局限（诚实清单）

1. 跨模型稳健性未做（模型约束）；
2. LLM-judge 打分信度未做重测一致率（人工复核通道预留未启用）；
3. 剥削率为代理口径；
4. 失业者在均衡中极少（自营无门槛制度假设）→ unemployed 组样本小；
5. 无政府/信贷/租金等制度（后续作为制度对照实验的自变量）；
6. v0 的"玩具资本主义"参数是使经济存活的手调组合，未做参数敏感性扫描。
