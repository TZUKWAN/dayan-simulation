## 标题（工作稿）
*Simulating Surplus: Large-Language-Model Agents as a Test Bench for Classical-Marxian Propositions*

## 1. Introduction（3-4段）
- 钩子：LLM 社会仿真 2023-2026 平台化（Generative Agents→OASIS/AgentSociety），但经济-分配层薄弱；"Marx × LLM simulation" 文献空白（四组 arXiv 查询零命中，2026-11 检索）。
- 主张：LLM agent 使异化叙事、拜物教话语、阶级意识应答首次可内生化为仿真变量；数值 Marx-ABM 小传统（Wright 2008; Cogliano–Veneziani–Yoshihara）+ 可复用平台 = 窗口期。
- 贡献清单：(i) 四层架构（确定性记账内核/语义层/测量层/效度层）；(ii) 首批 LLM 玩具经济中马理论结构性现象的涌现证据；(iii) 效度协议（遮蔽设计/规则基线差分/预注册/人设消融）。
