# msim v2 设计：面向社会科学理论的大模型仿真基础设施（社科仿真台）

> 版本：v2 设计稿（2026-11-07）。**纯设计文档，不含代码。**
> 背景：v0/v1 已交付 toy_capitalism（政治经济学单点实验，15 runs 全绿）。
> 愿景修正：项目不是"写论文"，而是搭建**可复用、可审计、可扩展的社会科学仿真基础设施**——
> 政治经济学、社会学、政治学、文化研究等学科的理论都能在其上做受控计算实验。
> 本设计的一切抽象都由 v0/v1 实战暴露的问题倒逼出来（每条注明出处）。

---

## 0. 愿景的三层表述

1. **对使用者（理论研究者）**：写一份声明式实验规约（scenario spec），就能获得一个受控、可审计、带效度证据的实验——不必懂仿真工程。
2. **对开发者（我们自己）**：每增加一个学科，只增加一个"理论包"（theory pack），不改动内核；内核的任何 bug 修复自动惠及所有学科。
3. **对学科（马理论/社科界）**：把"用仿真检验理论"从一次性的手工作坊，变成有**公共测量器具、公共效度标准、公共基准题库**的建制化实践。

一句话：**从"做实验"升级为"造实验台"。** 玩具资本主义（政治经济学）是它的第一个理论包和总装测试。

## 1. 五个核心设计决策（v0/v1 教训的沉淀）

### 决策 1：世界主权三分——引擎管状态、LLM 管意义、研究者管理论
v0/v1 最重要的架构发现：**记账权绝不能让 LLM 碰**（LLM 曾试图"表演理论"且算术不可信）；同时**理论词汇绝不能进 prompt**（遮蔽设计）。推而广之：

| 主权域 | 管辖 | 禁令 |
|---|---|---|
| **引擎（世界状态）** | 状态转移、账目、约束、不变量 | 不得调用 LLM 做任何算术或簿记 |
| **LLM（语义层）** | 意义负载的决策、叙事、应答、话语 | 不得写世界状态（只能发"意向"，由引擎裁决执行） |
| **研究者（理论层）** | 理论词汇、假设、测量口径 | 理论词汇只出现在测量端与规约中，永不出现在 agent 输入 |

这条三分法是从政治经济学包抽象出来的，但对所有学科成立：政治学里"合法性得分"由引擎记账、LLM 只做表态；社会学里"地位层级"由引擎维护、LLM 只做互动话语。

### 决策 2：不变量泛化——每学科定义自己的"守恒律"
v0/v1 的金钱守恒（残差 ~1e-13）证明：不变量是最好的正确性闸门。各学科必须显式声明自己的不变量，它们同时承担三个功能：正确性测试、可解释性、以及——在马理论场景里——**不变量本身就是理论的形式骨架**（两大部类平衡、剩余来源等）。

| 学科包 | 不变量示例 |
|---|---|
| 政治经济学 | 货币守恒（含设备部门回流）、技能/人口守恒 |
| 政治学（议会/选举） | 席位守恒、选票守恒、每 agent 每期一票 |
| 社会学（规范/地位） | 地位总量非负、规范采纳计数与人群计数一致 |
| 文化/媒介 | 信息总量流转守恒（产出=消费+丢弃） |

没有不变量的学科包不予立项——这是基础设施级的纪律。

### 决策 3：理论包（Theory Pack）是一等公民
每门学科 = 一个包，声明七件套：

```
理论包 = {
  实体模式:      agents/群体/组织/制度 的字段与关系
  制度规则:      引擎强制的约束（谁能做什么、资源怎么流）
  动作空间:      LLM 可输出的意向集合（自然语言 JSON）
  不变量:        守恒/约束律（供逐 tick 校验）
  测量器具:      分布/网络/话语/问卷/量表 的注册测量器
  校准靶:        真实世界 stylized facts（每个命题至少绑一个）
  基准复现:      该领域经典模型（本包的自证题）
}
```

研究者写实验 = 选一个包 + 写一份场景规约。**加一门学科不加一行内核代码。**

### 决策 4：场景规约（Scenario Spec）——实验即数据
实验不再是脚本，而是一份声明式文档（版本控制、可引用、可审查）：

```yaml
scenario: 合作社对照实验_v1
pack: 政治经济学包
population: {n: 200, 人设来源: 中性生成器, LLM比例: 0.25}
institutions: {制度: coop, 冲击: {tick: 120, 倍率: 0.45}}
measurement_plan: [基尼, 双形态拟合, 剥削记账, 异化量表, 阶级意识问卷]
validity_plan: {基线: 规则组, 消融: [人设], 种子: [7,43,101,202], 预注册: docs/prereg_v0.1.md}
claims_level: {机制主张: 需微观校准, 趋势主张: 允许}
```

规约里**强制填写** validity_plan 与 claims_level——没有效度方案的实验平台拒绝标记为"已检验"。

### 决策 5：效度是平台设施，不是每个实验的土办法
v0/v1 里手工做的效度动作全部下沉为平台内建件：

| 内建件 | 功能 | v0/v1 出处 |
|---|---|---|
| **遮蔽审计器** | 扫描全部 prompt，理论词汇零命中才放行 | 已通过审计 |
| **规则基线差分** | 同种子同参数的规则组自动生成 | H5 用的就是它 |
| **人设消融开关** | 一键去人设重跑 | H6（发现了强效应） |
| **种子批管理** | 预注册种子列表、跨种子 mean±std | campaign |
| **发散监测器** | 逐 tick 检测指标异常漂移（如基尼翻倍、价格触底） | LLM 双峰现象倒逼 |
| **判决信度仪** | LLM-judge 重测一致率自动计算 + 人工复核通道 | 94% 那次 |
| **预注册器** | SHA256 固化 + 校验命令 | 已建 |
| **守恒校验器** | 逐 tick 不变量检验，超标即中止 | 已建 |

## 2. 总体架构（五层 + 一条横切纪律）

```
┌─ 层5 证据与输出 ──────────────────────────────────────────┐
│  自动报告 · dashboard · 证据包(seed/config/log/cache)      │
│  主张分级声明(趋势/机制) · 判决表 · 预注册校验            │
├─ 层4 实验管理 ────────────────────────────────────────────┤
│  场景规约加载 · 预注册 · campaign编排(条件×种子)           │
│  效度闸门(遮蔽审计/守恒/消融/发散监测) · 判决器            │
├─ 层3 测量器具层 ──────────────────────────────────────────┤
│  测量器注册表：分布/网络/话语/问卷/量表/事件史            │
│  LLM-as-judge管线 + 关键词回退 + 人工复核通道              │
├─ 层2 智能体认知层 ────────────────────────────────────────┤
│  LLM决策(意向) · 记忆 · 人设 · 规则agent · 混合人口        │
│  意向→引擎裁决执行；LLM不直接写状态                        │
├─ 层1 理论包层(学科) ──────────────────────────────────────┤
│  政治经济学包 | 社会学包 | 政治学包 | 文化媒介包 | 组织包… │
│  每包：实体/制度/动作空间/不变量/测量钩子/校准靶/基准      │
├─ 层0 核心运行时(学科中立) ────────────────────────────────┤
│  事件溯源世界状态 · 调度器 · 种子纪律 · 不变量校验         │
│  全量日志(JSONL) · 响应缓存 · 中断/恢复 · 成本控制        │
└────────────────────────────────────────────────────────────┘
横切纪律：三主权边界(决策1) + 守恒校验(决策2) + 主张分级(趋势/机制)
```

**关键不变量**：层 0-1 永远不 import LLM 代码；层 2 永远不写状态；层 3 是理论词汇唯一合法栖息地；层 4-5 是研究者可触碰的唯一面。

## 3. 学科包蓝图（每包：制度变量 / 因变量 / 校准靶 / 基准复现题）

### 3.1 政治经济学包（已建成，v0/v1）
- 制度变量：所有制（私有/合作社/后续：计划-市场混合）、工资制度、再分配、需求冲击
- 因变量：剥削记账、劳动份额、阶级位置转移、异化量表、阶级意识问卷、拜物教话语
- 校准靶：Yakovenko 双形态、劳动份额区间、s′ 量级、CGSS（阶段2）
- 基准复现：Sugarscape 财富分布、价值规律涌现（Wright 式）
- **状态：包已活，是其余包的总装模板。**

### 3.2 社会学包（规范/地位/网络/失范）
- 世界观：agent 持"规范采纳意向"（LLM），在社会网络上互动；引擎维护网络结构、地位得分、规范采纳计数
- 制度变量：网络拓扑、惩罚强度、同质性/异质性人设、制度惩罚是否可见
- 因变量：规范涌现速率与覆盖率、地位流动性、群体极化、越轨-标签化率、失范量表（Durkheim→测量端）
- 校准靶：Schelling 分异阈值形态、bounded-confidence 极化区间、地位分布形态
- 基准复现：**Schelling 种族分异、Sugarscape 文化标签、Axelrod 规范博弈**（三题为本包自证）
- 与马理论的接口：地位/规范层 = "上层建筑"的可计算切片，与政治经济学包的阶级位置变量联动（基础-上层建筑传导的最可操作化切口）

### 3.3 政治学包（权力/选举/联盟/合法性）
- 世界观：职位与议席、投票、联盟组建、政策议程；引擎维护席位守恒、议程状态、合法性指数
- 制度变量：选举规则（多数制/比例制）、政党数、信息环境（媒介偏置）、镇压强度
- 因变量：选举结果分布、联盟稳定性、政策极化轨迹、合法性-服从关联、抗争动员阈值
- 校准靶：Duverger 定律（多数制→两党制）、中位选民收敛、Olson 集体行动门槛
- 基准复现：**Downs 中位选民、Duverger 选举规则、Olson 搭便车**
- 与马理论的接口：把合作社/私有制实验的政策干预（如冲击期失业救济）放进政治过程——政治经济学包产生"经济基础变量"，政治学包处理"政治反应变量"，两包共享同一人群

### 3.4 文化媒介包（话语/霸权/拜物教）
- 世界观：媒介生产/分发/消费，话语物化度、框架竞争；引擎维护信息流转守恒
- 制度变量：算法分发偏置、媒介所有制、审查/开放度
- 因变量：拜物教物化评分（v0/v1 已建通道）、话语框架占比、共识/分裂结构
- 基准复现：假新闻级联形态、回音室极化
- 与马理论接口：意识形态再生产测量（阿尔都塞命题的"指示器级"操作化——注意此命题只可做指示器，不可做检验，见调研 03 报告 D 节"不适"级）

### 3.5 组织/劳动社会学包
- 世界观：科层/车间/平台上的劳动过程（ Braverman 去技能化、Edwards 控制体制）
- 制度变量：监控强度、计件/计时、科层层级数、民主管理度
- 因变量：异化量表（复用政治经济学包器具）、去技能化率、控制-反抗动力学
- 校准靶：异化量表的组间方向预期（已证于 v0/v1）

### 3.6 后续候选包（愿景登记，不承诺）
法律与越轨包（标签化）、教育与再生产包（布迪厄文凭/文化资本）、家庭与性别包、历史制度包（长时段国家形成，Tilly 式）

## 4. 基础设施的自证：基准复现套件

**平台在任何新理论主张之前，必须先复现经典。** 这是基础设施级的"单元测试"：
- Schelling 分异（社会学）· Sugarscape 财富（经济学）· Axelrod 规范（社会学）
· Downs/Duverger（政治学）· bounded-confidence 极化（传播学）
每题既有规则版又有 LLM 版，**差异本身就是发现**（v0/v1 已示范：价值规律 rule +0.87 / LLM −0.42）。基准套件常驻回归：任何内核改动后自动全跑。

## 5. 实验生命周期（平台对外的唯一工作流）

```
写规约 → 遮蔽审计(门禁) → 预注册固化(SHA256) → 冒烟试跑(小规模)
→ campaign(条件×种子批量) → 效度闸门(守恒/消融/发散/判决信度)
→ 判决器输出(H假设逐条裁决,含 inconclusive) → 证据包归档 → 报告/dashboard
```

**任一闸门不过 = 实验不得标记为"已检验"**。H7（冲击实验）的 inconclusive 判决正是这套纪律的第一次实战证明：方向强但失业者叙事 n=9<20，平台如实报告而非迁就。

## 6. 诚实边界（平台自我限定，写入每层文档）

1. 平台产出**充分性证明**（能长出来）与**趋势主张**；永不产出历史规律的**必然性证明**；
2. LLM 是**实验装置**而非人类替身（Homo silicus 立场：分歧即研究对象）；
3. 机制主张必须配微观校准，否则自动降格为假设；
4. 跨模型稳健性目前是已知缺口（单模型约束）——平台把"底座模型"作为规约必填项与结果元数据，任何论文引用必须标注底座；
5. 辩证法/总体性/结构因果性**不在建模对象集合内**（与个体主义本体论正交，见调研 03 报告 D 节）。

## 7. 实施路线图（每阶段有验收标准，倒序依赖）

- **阶段 R0（平台化重构，2-3 周）**：把 v0/v1 的引擎从"政治经济学专用"抽成"学科中立内核 + 政治经济学包"。验收：全部现有测试在包化架构下通过；新建一个空包骨架只需声明七件套即可注册。
- **阶段 R1（基准复现套件，2 周）**：5 道基准题（§4）各出规则版+LLM 版，接入回归。验收：套件 CI 全绿，且每题有"经典形态 vs LLM 形态"的对照报告。
- **阶段 R2（社会学包，3-4 周）**：规范/地位/网络包 + 与政治经济学包的联动变量（阶级位置→地位/规范的先验差异）。验收：Axelrod/Schelling 复现 + 一个"阶级位置→规范采纳"的联动实验。
- **阶段 R3（政治学包，4-5 周）**：选举/联盟/合法性 + 跨包联动（经济基础冲击→政治反应）。验收：Duverger 复现 + "需求冲击→合法性/服从"联合实验。
- **阶段 R4（文化媒介包，3 周）**：复用拜物教通道，做话语框架竞争与意识形态指示器。
- **阶段 R5（人类校验与共同体化，持续）**：judge 人工复核上线（需用户参与 30-50 条）、规约注册表（实验可引用）、CGSS 定量靶接入（需数据授权）、跨模型消融（需用户放开约束）。
- **阶段 R6（演示与传播）**：GOD 控制室对接、教学场景包、对外文档站。

**依赖关系硬规则**：R1 的基准套件必须先于任何新学科包上线——新包的第一份产出必须是它的基准复现，否则平台不接收。

## 8. 平台级风险与对策

| 风险 | 对策 |
|---|---|
| 范围蔓延（什么学科都想做） | 包立项必须带七件套齐全的设计书；基准复现先行 |
| 学科知识失真（外行建模内行） | 每包绑定该学科的校准靶与基准题；引入学科顾问评审 |
| 不变量写错（守恒律本身错误） | 不变量评审 + 手算极限情形解析基准（v0/v1 已用此法） |
| LLM 成本随学科数膨胀 | 混合人口/按需决策/缓存三件套（v0/v1 实测：万次调用本地零成本） |
| 效度闸门被绕开 | 规约强制填写 validity_plan；报告自动嵌入闸门通过记录 |
| 发散态污染结论 | 发散监测器逐 tick 报警；发散 run 不删除但必须标注 |
| 平台被误读为"能证明历史规律" | 每份报告自动附加"充分性≠必然性"声明（层5 内建） |

## 9. 与现有资产的关系（一句定位）

v0/v1 的 toy_capitalism = **政治经济学包 v1 + 平台总装测试**；
llm_sim_survey 三份调研 = 平台的外部文献依据；
15 runs 的 campaign 数据 = 平台效度纪律的第一次实战演练。
**v2 平台重构时，政治经济学包的所有测量器具与效度件原样保留，只是从"专用"变为"第一个包"。**

## 10. 待用户拍板/参与的事项（不代劳）

1. **judge 人工复核**：30-50 条叙事的人工评分（平台信度硬通货）
2. **跨模型约束**：是否允许加载第二个 4B 级模型（qwen3-vl-4b，内存相当）
3. **学科优先级**：R2 社会学包 vs R3 政治学包，先做哪个
4. **CGSS 微观数据授权**（阶段 2 定量靶）
