# 指挥屏与双操作模式

2026-11-13。界面入口 `site/console/index.html`，新增组件 `command.js`、`command.css`。沿用现有 FastAPI、Three.js、Canvas、分析模块和实际 Agent，没有增加外部依赖。

## 操作模式

- **简易模式**：首次打开默认使用，AI 常驻。建模、改参数、分析使用原 Agent；报告、导出和已有结果的明确查看命令在对话中连接实际工作台操作。可附加真实 CSV/JSON/GeoJSON 数据文件。不要求填写模型参数表。
- **专业模式**：保留 AI，通过侧栏页签切换到全部参数。参数名、类型、默认值、边界和运行中可变标志来自 `/api/models/contract/{id}`；初始化参数可在新运行中设置，只有合同允许的参数才能用于运行中干预。公开完整参数，不以几条通用滑杆替代。
- 专业运行同时提供步数、dt、随机种子、定时干预、输入数据映射和检查点位置。高级结构参数使用 JSON，后端仍严格验证。执行创建独立归档，不改写当前保存结果。
- 从模型库/案例选择模型先载入参数控制台，点击执行才计算。切模式不计算，不清空结果、时间位置或当前 AI 草稿。模式在当前浏览器中保存。

## 首屏数据

中央动画继续使用实际存档状态；两侧显示全部观测的指标卡/独立尺度迷你趋势、相邻帧位置变化构成、时间序列和主体状态分布。下方提供空间结构、方案比较、主体属性轨迹、相关矩阵、单步变化和字段统计，并保留事件和需求对应依据。

- 指标卡最多同时呈现前 16 项；专业指标选择器和 AI 指标命令可以访问实际全部数值观测。
- 相关矩阵显示前 8 项数值观测，使用当前分析窗口。常量列、有效配对不足 3 条显示“—”；相关不代表因果。
- 单步变化是相邻有效观测值之差，不冒称单位时间变化率。
- 主体运动按同 ID 的相邻保存帧计算，坐标差超过 `1e-9` 记为变化；首帧/没有位置时不推算。
- 默认分布排除数值 ID，优先速度、到达/离开状态；默认选中一个实际主体展示轨迹，仍可自行切换。
- 汇总模型没有主体时，显示真实指标的各自绝对峰值归一强度，并注明没有个体状态；不补造人群或地理对象。
- 没有 URL 指定记录时，读取上次仍在近期历史中的记录，或最新完整归档；默认暂停并标记“归档状态回放 · 非实时采集”。没有归档就显示空态，不自动运行演示。

## 明确的对话查看命令

以下命令操作已有归档，不调用云模型或重新求解。其他需求继续走真实 Agent。

| 输入 | 实际动作 |
|---|---|
| `查看第2个方案` | 切换当前结果集合中的第 2 次实际运行 |
| `查看车辆密度趋势` / `查看density指标` | 按真实字段或显示名称切换指标 |
| `回放到模型时间3.8` | 暂停并定位已有结果的回放位置 |
| `生成研究报告` | 调用现有归档报告接口，返回真实 DOCX |
| `导出原始数据` / `导出研究包` | 提供当前归档的实际 CSV/研究包下载地址 |

输入错误的方案号、指标名或时间范围会报告缺口，不用其他数据代替。高级查看命令当前是明确句式匹配，不表示任意口语都支持对应的界面动作。

## 验收与限制

证据在 `.claude/command_modes_20261113/`：13 项界面/执行单元、7 类独立数值核对、4 个 JS 脚本语法检查，正式只读部署核验和实际截图。报告为 `CHANGE_REPORT.md`，最终审计为 `FINAL_AUDIT.json`。

数值全部来源于已有模型状态、观测及其明确派生统计，增加视角不表示增加现实采集数据。模型固有科学有效性、缺失机制、三维物理和大规模性能边界仍然存在；本次没有逐模型、逐硬件重新审查。复杂参数的适用组合仍以实际后端合同与执行错误为准。
